# My Portfolio Website

Modern full-stack developer portfolio built with Next.js, Tailwind CSS, Framer Motion, and FastAPI.

🔗 Live Website: https://babil-portfolio.vercel.app/

## Features
- Responsive modern UI
- Smooth animations
- AI chatbot integration
- Projects & skills showcase
- Dark futuristic theme

## Tech Stack
- Next.js
- React
- Tailwind CSS
- FastAPI
- Framer Motion
